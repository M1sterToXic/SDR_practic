# SDR_practic

Учебная практика по курсу программно-определяемого радио (SDR) на базе Adalm-Pluto SDR.

## Отчёты по практическим работам

* [Практическая работа №1](doc/1_Lab.md) — Основы структурной схемы цифровой радиосвязи, приём FM-радиовещания
* [Практическая работа №2](doc/2_Lab.md) — Захват и спектральный анализ Wi-Fi сигналов в диапазоне 2.4 ГГц
* [Практическая работа №3](doc/3_Lab.md) — Инициализация SDR через библиотеку SoapySDR (C++), приём IQ-отсчётов и временная синхронизация
* [Практическая работа №4–5](doc/4-5_Lab.md) — Организация связи между двумя SDR (C++): разнесение частот приёма и передачи, передача пачек импульсов
